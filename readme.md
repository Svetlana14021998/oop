# Система управления личными финансами

Консольное приложение на Java для управления личными финансами, отслеживания доходов, расходов и контроля бюджетов.

## Основной функционал

* Многопользовательская авторизация: Регистрация и вход по логину и паролю. Пароли надежно хешируются с помощью
  алгоритма BCrypt.
* Управление операциями: Добавление доходов и расходов.
* Управление категориями: Создание категорий для доходов и расходов, переименование существующих категорий.
* Бюджетирование: Возможность установки, изменения или снятия лимита бюджета для любой категории расходов.
* Аналитика и статистика:
    * Вывод общего баланса, общей суммы доходов и расходов.
    * Детализация по каждой категории.
    * Подсчет доходов/расходов по нескольким выбранным категориям (с уведомлением, если категория не найдена).
* Переводы между пользователями: Возможность перевода средств другому пользователю по его логину с корректным списанием
  и зачислением.
* Умные оповещения:
    * Уведомление при превышении лимита бюджета по категории.
    * Уведомление при достижении 80% от лимита (предупреждение).
    * Уведомление, если общие расходы превысили общие доходы.
* Валидация ввода: Защита от некорректного ввода (буквы вместо цифр, отрицательные суммы, пустые строки).

## Архитектура и стек технологий

Проект написан с соблюдением принципов ООП и разделения ответственности (Layered Architecture).

Стек технологий:

* Java 17
* Maven (сборка проекта)
* Gson (сериализация/десериализация данных в JSON)
* Lombok (сокращение шаблонного кода)
* jBCrypt (хеширование паролей)
* JUnit 5 (модульное и интеграционное тестирование)

Структура пакетов:

* `model` — бизнес-сущности (User, Wallet, Category, Operation).
* `service` — бизнес-логика (AuthService, FileService).
* `ui` — взаимодействие с консолью (ConsoleUI).
* `controller` — управление потоком выполнения (AppRunner).
* `utils` — вспомогательные утилиты (StringUtils).

## Хранение данных и отказоустойчивость

* Формат данных: Данные хранятся в памяти во время работы приложения и сохраняются в файлы формата JSON (с кодировкой
  UTF-8).
* Разделение файлов: Список пользователей хранится в `users.json`, а кошелек каждого пользователя — в отдельном файле
  `wallet_<login>.json`.
* Автосохранение: Данные кошелька сохраняются в файл сразу после каждого изменения (добавление операции, смена бюджета,
  перевод и т.д.). Это защищает данные от потери в случае аварийного завершения программы.
* Защита от сбоев: Если при загрузке данных (пользователей или кошелька) или при сохранении возникает ошибка (например,
  проблемы с доступом к файлу или повреждение JSON), приложение выводит сообщение об ошибке и аварийно завершает работу
  (System.exit (1)), чтобы избежать работы с некорректным состоянием данных.

## Доступные команды

После ввода любой команды необходимо следовать указаниям, которые приложение выводит в консоль (например, ввести сумму,
название категории или логин получателя).

### Команды главного меню (до авторизации):

* `reg` — зарегистрировать нового пользователя.
* `login` — войти в систему под существующим логином.
* `exit` — завершить работу приложения.

### Команды меню пользователя (после авторизации):

* `add_in` — добавить доход (требуется указать категорию и сумму).
* `add_out` — добавить расход (требуется указать категорию и сумму).
* `add_cat` — создать новую категорию доходов или расходов (можно сразу задать бюджет для расходов).
* `change_cat_name` — изменить название существующей категории.
* `change_cat_budget` — изменить или снять бюджет для категории расходов.
* `show_cat` — показать список всех категорий доходов и расходов (с указанием бюджета).
* `show_budget` — показать полную статистику (общий доход, доходы по категориям, общие расходы, бюджеты по категориям,
  текущий баланс).
* `sum_cat` — подсчитать сумму доходов или расходов по нескольким выбранным категориям.
* `transfer` — перевести деньги другому пользователю по его логину.
* `help` — вывести список всех доступных команд.
* `exit` — выйти из профиля и вернуться в главное меню.
